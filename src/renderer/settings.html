How it feels

Keys carry their keyboard position into the stereo field: left-side keys lean left, right-side keys lean right. Space, Return and Delete get their own bigger samples, and every press gets a slightly different take and pitch.

Kiki

Tap Kiki plays one key and makes it press along. The three buttons play the agent cues (done, needs you, error) with the sound and the face.

Your coding agents

Hear a cue when Claude Code, Cursor or the Codex CLI is done, needs you, or fails. Klick adds one hook to each config file and backs it up first.
